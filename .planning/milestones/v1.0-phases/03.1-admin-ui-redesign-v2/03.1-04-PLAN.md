<objective>
Ship the verb-engine command palette: server-side static registry + role-filtered JSON
endpoint + Razor component shell + TopNav search-trigger button. The palette is the
showpiece UX feature of this redesign — operators will spend their muscle memory here
(CONTEXT § Specifics). Plan 03 already shipped the JS bundle that renders the palette
overlay and dispatches actions; this plan provides the data and the Blazor-side mount.

The two-step flow (D-10) works as follows: user presses Cmd+K → JS opens overlay → JS
fetches `/admin/api/commands` once and caches → operator types verb (e.g. "ban") → JS
filters rows → operator selects "Ban player" → JS swaps to target-search mode and fetches
`/admin/api/players/search?query=…` → operator picks a player → JS calls
`window.GKAdmin.invokeDialog('ban', targetId, displayName)` which routes through
`MainLayout.OpenDialog` (Plan 03) → MudDialog opens with parameters pre-loaded.

**Purpose:** D-09 mandates the verb-engine palette for v1; D-10 mandates the two-step
flow; D-11 mandates server-side role filtering (never gray, always absent). The functional
dialog flow is reused unchanged — this plan adds discoverability.

**Output:** registry + DTO + endpoint + Razor + scoped CSS + TopNav search-trigger +
MainLayout palette mount + live (non-skipped) component test.
</objective>

    /// <summary>
    /// Returns the role-filtered command list consumed by the Phase 03.1 Cmd+K palette.
    /// Per CONTEXT D-11 the server discards superadmin-only rows for non-superadmin operators
    /// — never grayed, always absent. The palette JS renders rows verbatim.
    /// </summary>
    private static Task<IResult> GetCommandsAsync(HttpContext http)
    {
        var role = http.User.FindFirst(System.Security.Claims.ClaimTypes.Role)?.Value
                   ?? AdminRoles.Admin;
        var isSuper = string.Equals(role, AdminRoles.Superadmin, StringComparison.Ordinal);
        var visible = AdminCommandRegistry.AllCommands
            .Where(c => isSuper || !c.RequiresSuperadmin)
            .Select(c => new AdminCommandDto(c.Id, c.Label, c.Category, c.RequiresTarget))
            .ToArray();
        return Task.FromResult<IResult>(Results.Ok(visible));
    }

    private IReadOnlyList<AdminCommandDto>? _visible;
