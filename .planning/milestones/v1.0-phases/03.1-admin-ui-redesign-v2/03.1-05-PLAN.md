| Operator localStorage ↔ DOM `[data-*]` attrs | unchanged from Plan 03; all writes go through `gamekit-admin.js` saveTweaks |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-03.1-05-01 | Tampering | TweaksPanel.razor markup | mitigate | All option labels are static literals in the Razor template; no operator-controlled input flows into the markup. Razor `@` interpolation auto-encodes if labels were dynamic. The `data-tweak` and `data-value` attributes contain only the 5 known keys + their enum-shaped values. |
| T-03.1-05-02 | Tampering | localStorage `gamekit.admin.tweaks` JSON | accept | Self-inflicted only — operator can already mutate their own browser state. The JSON contains 5 enum-shaped values; a malicious value (e.g. `density: ""`) is silently coerced to defaults by the Plan 03 `applyAttrs` function (`t[k] || DEFAULTS[k]`). |
| T-03.1-05-03 | Information Disclosure | TweaksPanel right-drawer rendered while logged out | accept | TweaksPanel is mounted only inside MainLayout; LoginLayout has no mount. Even if an attacker fakes the `[data-tweaks-open]` attribute, the panel only reveals static option labels — no PII, no role information, no business state. |
| T-03.1-05-04 | Tampering | TopNav onclick handler `JS.InvokeVoidAsync("GKAdmin.openTweaks")` | mitigate | The handler invokes a known JS function name with no arguments; the function only flips an attribute. No user input flows. |
| T-03.1-05-05 | (carried-over from Phase 03; no change in this plan) | AdminCspNonceMiddleware / AntiforgeryValidationFilter | mitigate | Phase 03 mitigations remain in force. The TweaksPanel markup is server-rendered Razor — no inline scripts, no `(MarkupString)`, no XSS surface. |
