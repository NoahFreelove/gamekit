## Decisions Made

- **BCL-only contrast computation.** AccessibilityTests carries its own `RelativeLuminance` + `ComputeContrastRatio` helpers (~30 LOC) rather than pulling a color-math NuGet. Aligns with Pitfall 1 (no runtime dep for what System.Math can do) and the SC#5 zero-runtime-package contract.
- **Single-regex `:focus-visible` assertion (W8).** Plan-checker iteration 1 caught a false-positive risk in the original two-substring approach. The live test enforces both `outline: 2px solid var(--accent)` and `outline-offset: 2px` inside the same declaration block via `[^}]*`.
- **Hex-literal InlineData rather than CSS-token parsing.** The test asserts against the empirical hex values from RESEARCH §Accessibility — if anyone changes the violet token, they must update both the CSS and the test, which is exactly the desired coupling for a phase-gate fact.
