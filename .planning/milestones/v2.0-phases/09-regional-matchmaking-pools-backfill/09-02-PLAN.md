| Threat ID | Category | Component | Disposition | Mitigation Plan |

| T-09-02-02 | Elevation of Privilege | enqueue endpoint authz | mitigate | POST /api/mm/queue already carries .RequireAuthorization() + player id sourced from JWT NameIdentifier (unchanged); RegionName does not alter the auth gate |

| T-09-02-04 | Information Disclosure | region_not_allowed error detail | accept | Detail echoes the rejected pool name only (already client-supplied); no server-side region list is leaked beyond the binary allowed/not-allowed outcome |
| T-09-02-SC | Tampering | npm/pip/cargo installs | accept | No package installs this phase (09-RESEARCH.md Package Legitimacy Audit: none); no new dependency surface |
