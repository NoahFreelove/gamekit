## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| admin browser → /admin/api/players/merge | untrusted POST crosses into a destructive superadmin op |
| HTTP response → admin | response must not leak the merged-away source player_id |
| non-superadmin admin → merge endpoint | a lower-privilege admin must be denied |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-10-04-01 | Elevation of Privilege | non-superadmin invokes merge | mitigate | RequireAuthorization(AdminPolicies.Superadmin); SC#5_AuthZ test asserts 403 for admin-role cookie |
| T-10-04-02 | Tampering | CSRF forces a merge via the admin cookie | mitigate | AddEndpointFilter&lt;AntiforgeryValidationFilter&gt; on the POST; harvested-token test exercises the happy path |
| T-10-04-03 | Information Disclosure | response leaks source player_id | mitigate | MergePlayersResponse has no SourcePlayerId field; conflict/not-found paths echo no source id; SC#5_ResponseShape asserts the source GUID is absent from the body |
| T-10-04-04 | Denial of Service | scripted bulk merges | mitigate | RequireRateLimiting(AdminMergePolicy) 5/min/IP |
| T-10-04-05 | Tampering | malformed input (source==target, empty GUID) | mitigate | ValidationEndpointFilter&lt;MergePlayersRequest&gt; rejects before the merge tx opens |
| T-10-04-06 | Repudiation | merge not attributable | mitigate | actorId from GetAdminId(http) flows to the audit row; SC#4_AuditRow asserts it |
| T-10-04-SC | Tampering | npm/pip/cargo installs | accept | No package installs (zero new deps per 10-RESEARCH Package Legitimacy Audit) |
</threat_model>
