<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| host network → container ports | Any container port published to the host is reachable by anything on the host; app metrics must not be among them |
| docker registry → operator pull | Image tags determine exactly what code runs; `:latest` is a tampering/supply-chain vector |
| sample app (host) → Collector (:4317) | Unauthenticated OTLP push on localhost — acceptable for a dev-only sample |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-13-METRICS | Information Disclosure | Prometheus service port | mitigate | `prometheus:` service has NO `ports:` mapping — host-isolated on obs-internal; proven by the `curl http://localhost:9090` MUST-FAIL acceptance criterion (ISOLATION-OK) — success criterion #3 |
| T-13-SC-IMG | Tampering / Supply chain | Docker image tags | mitigate | Every image tag pinned explicitly (postgres:17.9, redis:8.6.2, otel/opentelemetry-collector-contrib:0.154.0, prom/prometheus:v3.11.2, grafana/tempo:2.6.1, grafana/grafana:13.0.2); `grep -c ':latest'` == 0 acceptance criterion |
| T-13-OTLP | Spoofing / Tampering | OTLP endpoint on localhost:4317 (unauthenticated) | accept | Dev-only sample stack; no mTLS needed locally; README documents that production deployments must secure the OTLP endpoint — per security_requirement (document, do not gate) |
| T-13-AGPL | Licensing (Tampering of distribution obligations) | Tempo + Grafana AGPLv3 | accept | Operator-pulled containers; GameKit neither links nor distributes them (RESEARCH §GPL/AGPL Licensing Analysis); README documents the Jaeger Apache-2.0 swap for operators who prefer it |
</threat_model>
