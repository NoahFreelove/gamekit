<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| client → enqueue HTTP handler | client-influenceable input; could attempt to supply a forged traceparent |
| Redis ticket hash → ticker | stored traceparent is data restored into a trust-bearing parent context |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-15-03-TRACE-INJ | Spoofing / Tampering | stored `otel.traceparent` restored in the ticker | mitigate | GameKit writes the traceparent SERVER-SIDE from `Activity.Current.Id` at enqueue — it is NEVER read from client-supplied request fields. The enqueue path does not let a client set `otel.traceparent`. The ticker restores via `ActivityContext.TryParse` (non-throwing); a parse failure → start a NEW root span, never throw (Pitfall 1). A forged value at worst mis-parents a span in the operator's own Tempo (no auth/data boundary crossed). |
| T-15-03-PII | Information Disclosure | traceparent stored as a Redis hash field | mitigate | `traceparent`/`tracestate` are W3C trace identifiers (random trace/span ids), not PII; stored as hash FIELDS (not OTel tags) so they never enter the span-attribute denylist surface. No player/ticket id is added as a span attribute on the MatchFormation span (GK0001 guards). |
| T-15-03-SAMPLE | Denial of Service | unbounded trace volume | accept | Sampling decision propagates from the enqueue span's flags (non-sampled parent → non-sampled formation span) — GameKit does not force-sample; trace volume is governed by the operator's sampler. |
| T-15-03-SC | Tampering | package installs | accept | No new packages — in-box `System.Diagnostics.{Activity,ActivityContext,ActivityLink}`. |
</threat_model>
