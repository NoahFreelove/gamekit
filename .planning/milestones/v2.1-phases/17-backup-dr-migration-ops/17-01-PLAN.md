<objective>
Establish the DR-04 migration-rollback convention and the DR-05/DR-07 timestamp-ordering foundation. This plan rewrites every existing migration `Down()` body across all six GameKit packages to throw `NotSupportedException`, and adds five no-op "ordering marker" migrations so the per-package latest-timestamp chain strictly ascends in canonical application order.

Purpose: Phase 17 changes the migration convention — destructive `Down()` rollback is replaced by "restore from backup". This plan makes the codebase conform so the GK0003 analyzer gate (Plan 02) compiles green when it turns on, and so `MigrationTimestampTests` (Plan 02) passes.

Output: 14 converted migration files + 5 new marker migration files. No DDL behavior change (markers are no-op; conversions only touch the never-run `Down()` path).
</objective>
