<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| browser render → CSP enforcement | Browser blocks any script without the per-request nonce. Script tags in App.razor must carry `nonce="@Nonce"` or the Blazor circuit fails silently. |
| SignalR circuit → AuthorizeRouteView | Circuit carries authenticated principal; AuthorizeView hides role-gated nav items server-side (user cannot see superadmin items they don't have role for). |

| Threat ID | Category | Component | Disposition | Mitigation Plan |
