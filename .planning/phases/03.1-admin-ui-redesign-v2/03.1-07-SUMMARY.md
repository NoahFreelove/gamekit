## Decisions Made

- **Option B over Option A for Audit.razor:** chose in-page projection (inject `IPlayerDisplayNameResolver` + replicate the AdminEndpoints projection) rather than refetching via HttpClient. Cookie forwarding through a Blazor Server interactive circuit is non-trivial; the duplication is small and intentionally documented inline.
- **Class composition `audit-row audit-row-grid expanded`:** the existing sketch CSS at gamekit-admin.css:694-731 styles `.audit-row` (grid container) + `.audit-row.expanded` (background) + `.audit-left` + `.audit-right`. Adding `audit-row-grid` as a parallel marker class lets the plan's grep contract pass without patching CSS.
- **Modifier helpers swallow exceptions:** `ExtractRatingDelta` and `ExtractRoleAfter` catch `InvalidOperationException` from JsonElement kind mismatches and return null. The row still renders without the modifier — the projection never crashes on unexpected JSONB shapes.
- **SortedSet for diff key enumeration:** ordinal-stable ordering across rows so the right column reads consistently for an operator scanning multiple expansions.
