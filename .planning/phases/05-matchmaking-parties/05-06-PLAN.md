## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Player → /api/mm/proposal/{id}/accept (Plan 05-08 endpoint) | Player must not be able to accept a proposal they are not in (Spoofing) — Plan 05-06's ProposalService verifies ticketId ∈ proposal.ticketIds |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-05-06-01 | Spoofing | Player accepts a proposal they are not in | mitigate | ProposalService.AcceptAsync verifies `proposal.ticketIds.Contains(ticketId)` before SET; returns NotInProposal (mapped to 403 by Plan 05-08 endpoint) |
| T-05-06-02 | Tampering | Late accept races against proposal sweeper | mitigate | ProposalCompleteScript runs SADD+SCARD inside Lua atomically — either the accept makes it into the set before the sweeper deletes the proposal, or the sweeper has already deleted the proposal hash and AcceptAsync's HGETALL returns ProposalNotFound (clean failure) |
| T-05-06-03 | Tampering | Decline writes DeclineHistory but Redis re-ZADD fails (Postgres tx commits, Redis tx fails) | mitigate | Order: INSERT DeclineHistory FIRST (durable); THEN re-ZADD via Lua (Lua is atomic). On Lua failure, the worst case is the accepting party's ticket is lost — recovered by the reconciler within StaleTicketThresholdMinutes (Plan 05-07). The decline_history row's cooldown effect on the declining player is preserved regardless. |
| T-05-06-04 | Tampering | Player accepts after game_session already created | mitigate | After AllAccepted result, the proposal hash + accept set are deleted (in the same Lua step that creates the game_session — wait, the session creation is in Postgres not Lua). Concrete: ProposalCompleteScript sets `state=complete`; ProposalService then INSERTs game_session; if a late AcceptAsync arrives during this window, it reads HGETALL proposal → state="complete" → returns AlreadyAccepted (idempotent). Document this race window in XML doc. |
| T-05-06-05 | Information Disclosure | Time-based cooldown leak via DateTime.Now | mitigate | All cooldown time math uses IClock.UtcNow (Pitfall §4) — verified by grep |
