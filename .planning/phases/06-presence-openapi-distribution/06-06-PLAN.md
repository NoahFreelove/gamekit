## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| /openapi/v1.json → anonymous public | OpenAPI doc is publicly readable (no auth required to read the doc itself) — discloses the GameKit player-facing API surface |
| GameKitInfoTransformer → GameKit.OpenApi.Internal.GameKitMarker | Transformer reads a const compiled into the same assembly; no cross-assembly reflection in this path |
| GameKitBearerSchemeTransformer → IAuthenticationSchemeProvider | Reads the registered auth schemes from DI; no external IO |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-06-06-01 | Information disclosure | OpenAPI doc leaks admin endpoint shapes | mitigate | ShouldInclude inline lambda filters out every path starting with `admin` (D-08, D-19; NO trailing slash per D-19 verbatim so the bare `/admin` route is also caught). | T-06-06-02 | Information disclosure | OpenAPI doc leaks connection strings / secrets via endpoint response schemas | accept | Connection strings + JWT signing keys are NEVER in any endpoint response body. The doc only describes routes, parameters, and response schemas — public surface only. |
| T-06-06-03 | Tampering | A consumer registers their own AddOpenApi(...) with conflicting transformers + ShouldInclude lambdas | accept | The Microsoft.AspNetCore.OpenApi document is keyed by documentName; if a consumer registers a second AddOpenApi("v2", ...), it produces a separate doc. | T-06-06-04 | Information disclosure | OpenAPI doc exposes presence heartbeat endpoint with bearer requirement, revealing that authenticated players can write heartbeats | accept | This is the intended public contract — any consumer / integrator needs the doc to know how to call /api/presence/heartbeat. The endpoint is JWT-protected; exposing its existence is not a vulnerability. |
| T-06-06-05 | DoS | /openapi/v1.json is generated on every request → could be expensive under load | accept | Microsoft.AspNetCore.OpenApi caches the document per documentName by default per the .NET 10 release notes. A consumer who wants to disable runtime regeneration can switch to build-time OpenAPI generation via Microsoft.Extensions.ApiDescription.Server (Plan 06-06 does not include build-time generation; consumer choice). |
| T-06-06-06 | Spoofing / Info disclosure | OpenAPI doc applies bearerAuth globally → misleading for /auth/login (anonymous) | accept (with note) | RESEARCH Pitfall 7 lines 944-948 acknowledges this; v1 ships global bearer; future iteration may add an operation transformer that REMOVES the security requirement for `[AllowAnonymous]` endpoints. Not a Phase 6 blocker — the doc still correctly says "calling these endpoints requires JWT" for the 95% of endpoints that DO require JWT. |
| T-06-06-SC | Tampering | npm/pip/cargo installs | accept | Microsoft.AspNetCore.OpenApi 10.0.8 is first-party Microsoft NuGet, pinned by Plan 06-01. No new NuGet dependencies added in Plan 06-06. |
