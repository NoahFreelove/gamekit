| Threat ID | Category | Component | Disposition | Mitigation Plan |

Generated README.md repeats the manual instructions. |
| T-06-09-02 | Tampering | Template ships a dev RSA keypair script that produces predictable keys if reused in prod | mitigate | (a) scripts/gen-test-rsa-pem.sh generates a random 2048-bit RSA keypair per invocation (not deterministic); (b) Plan 06-10's docs/ops/jwt-keys.md prominently warns operators to rotate before production; (c) dev key paths in appsettings.Development.json indicate the keys are dev-only by location convention. |
| T-06-09-03 | Supply chain | GameKit.Templates NuGet package could be tampered with on the feed | mitigate | (a) Package is GPL — source is in-tree + auditable; (b) DIST-04 test asserts package shape (catches malformed packaging); (c) NuGet feed-level package signing is operator-deployable (consumer choice). |
| T-06-09-04 | Information disclosure | Template content contains the dev gamekit_reader_dev / gamekit_owner_dev passwords in appsettings.json | mitigate | Passwords are DEV-ONLY (match docker/postgres/init/01-roles.sql); Plan 06-10's docs/ops/postgres-roles.md instructs operators to rotate before production. | T-06-09-SC | Tampering | npm/pip/cargo installs | accept | No npm/pip/cargo installs. Microsoft.TemplateEngine.Authoring.Templates is SDK-aligned per Phase 6 RESEARCH (no explicit pin needed). |
