<objective>
Ship `GameKit.Auth.Apple` (AUTH-20, AUTH-22): an opt-in sibling package wrapping `AspNet.Security.OAuth.Apple` 10.0.0 with Sign-In-with-Apple. The package generates a fresh ES256 client secret per token exchange (`GenerateClientSecret = true`, `ClientSecretExpiresAfter < 180 days`) from a `.p8` private key, stores the Apple `sub` claim (NOT email) as `external_id` under the existing `UNIQUE(provider, external_id)` contract, and persists relay email + name to `PlayerIdentity.Metadata` JSONB on FIRST login only.

Purpose: Apple Sign-In is mandatory for iOS game distribution; getting the ES256-per-exchange and sub-as-identity details right prevents a 6-month-clockwork production outage and identity-confusion bugs.

Output: Apple package (5 source files) + test project. ZERO migrations.

This plan is `autonomous: false` because the LIVE Apple round-trip needs real Developer credentials (.p8 key + Service ID). The package, options-shape, DI wiring, sub-extraction, and first-login metadata logic are ALL automated and unit-tested with mocked principals; only the end-to-end live smoke is a human-verify gate. Depends on Plan 02 (07-02) for the `AspNet.Security.OAuth.Apple` + `Microsoft.IdentityModel.Protocols.OpenIdConnect` pins and sln entries. Shares NO files with Plans 03/05/06 — runs parallel in Wave 2.

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Apple IdP → OnCreatingTicket | The aspnet-contrib Apple handler verifies the id_token; the verified principal's `sub` crosses into AppleOAuthProvider as the trusted identity key. |
| .p8 private key → host process | The ES256 signing key crosses from secret storage into memory for per-exchange client-secret generation. |
| OnCreatingTicket → player_identities/Metadata | Identity upsert + first-login relay-email persistence. |

| Threat ID | Category | Component | Disposition | Mitigation Plan |

A fresh ES256 JWT is generated per exchange. |
| T-07-04-02 | Information Disclosure / Identity Confusion | Apple private-relay email used as external_id | mitigate | OnCreatingTicket extracts `sub` only (`FindFirst("sub")`); relay email goes to Metadata JSONB. Grep gate for `FindFirst("sub")`; the provider stores externalId=sub. |
| T-07-04-03 | Information Disclosure / Elevation | `.p8` key leaked via image layer or logs | mitigate | Key loaded from `PrivateKeyBase64` (env/secret), documented in GameKitAppleOptions XML as never-bake-into-image; the key bytes are never logged. UsePrivateKey imports via BCL ECDsa and discards the base64 reference. |

Pinned by Plan 02. No `[ASSUMED]`/`[SUS]` — no blocking legitimacy checkpoint required. |
