<objective>
Build the PII/secret span-attribute lint gate — a repo-build-only Roslyn `DiagnosticAnalyzer` (`GK0001`)
that fails the build if any `SetTag`/`AddTag` call in `src/` uses a key containing a PII token, plus a
committed allow-list and an analyzer test project. This is the FIRST thing built in Phase 13 (D-06 order
mandate): it must be green BEFORE any attribute normalization (Plan 03) or `GameKitTelemetry` constants
(Plan 02) land, so new/changed tags are guarded as they are written.

enforcement is the only reliable gate — runtime checks are too late.
Output: `PiiAttributeAnalyzer.cs` in the existing `GameKit.Build` project, `pii-allowlist.txt`, the
`AdditionalFiles` wiring, the two new analyzer-testing NuGet pins, and `tests/GameKit.Build.Tests/`.
