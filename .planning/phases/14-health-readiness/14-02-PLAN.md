| T-14-05 | Information Disclosure | reporter readiness feeding aggregate description | mitigate | Reporters return only `bool`; the aggregate check (Plan 01) renders a count-only description ("N of M migration sets pending") — no table names, schemas, or connection details cross the boundary (D-12). |
