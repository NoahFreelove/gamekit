<objective>
Extend the `MatchmakingTestApp` harness so two in-process replicas can share one Postgres database and Redis with a short lock TTL and a service-override hook, then write the SCALE-04 split-brain CI gate (`MatchmakerSplitBrainTests`) and the SCALE-03 idempotency verification. The split-brain test pauses Replica A's ticker mid-claim past the TTL so Replica B acquires the lease and forms the match — asserting zero duplicate `game_sessions` rows and no ticker gap longer than one lock TTL. The idempotency test proves concurrent formation for one key yields exactly one row.

Purpose: Prove the SCALE-01/02/03 implementation actually prevents duplicate matches under realistic leader churn — this is the required CI gate (RESEARCH §Test Architecture). Verifies SCALE-04 and SCALE-03.
Output: Harness extension + `DelayingChaosInterceptor` test double + `MatchmakerSplitBrainTests` with two facts.
</objective>
