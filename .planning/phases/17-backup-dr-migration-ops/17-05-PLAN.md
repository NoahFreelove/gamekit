|----------|-------------|
| backup dump file (PII) ↔ bind-mounted host dir | the custom-format dump contains player rows; it lives in a test temp dir during the round-trip |
| restored DB → app health check | the restored schema must satisfy all 6 IMigrationReadinessReporter probes for /health/ready to pass |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-17-05-01 | Tampering | restoring an untrusted dump | mitigate | The round-trip restores ONLY a dump produced by this test's own pg_dump in the same run — there is no untrusted-dump ingestion path here. Operator-facing untrusted-restore risk is documented in the restore runbook (Plan 06) |
| T-17-05-02 | Information Disclosure | dump file contains seeded PII | accept | Test-only synthetic player row in an ephemeral container temp dir, deleted on cleanup; no real PII, no persistence beyond the test |
| T-17-05-03 | Denial of Service | pg_dump hangs on password prompt | mitigate | PGPASSWORD=postgres_test prefixed in the ExecAsync bash command (Pitfall 3) so pg_dump/pg_restore never block on an interactive prompt |
</threat_model>
