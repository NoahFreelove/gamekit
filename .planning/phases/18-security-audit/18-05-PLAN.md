<objective>
Preserve the air-gap guarantee (SEC-05) and the refresh-token + CSRF invariants (SEC-06). SEC-05 has a confirmed production gap: the aspnet-contrib Apple/Google OAuth handlers use their own backchannel HttpClient that does NOT route through EgressAllowListHandler, so Apple/Google sign-in can currently reach arbitrary hosts. This plan wires those backchannels through the allow-list and adds Apple/Google hosts to it, then adds the egress static-grep CI gate, the egress + refresh-hash tests, and the CSRF 400 regression.

Purpose: Guarantee no package makes outbound HTTP beyond configured OAuth provider hosts, that refresh tokens are never stored raw, and that admin mutations require antiforgery.
Output: Apple/Google egress wiring fix + allow-list additions; EgressAuditTests; RefreshTokenHashingTests; CsrfRegressionTests; CI grep steps.
</objective>
