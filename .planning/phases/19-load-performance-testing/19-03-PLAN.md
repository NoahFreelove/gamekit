<objective>
Build the PERF-06 regression gate: a compiled `benchmarks/CompareBaseline` console tool that diffs a BenchmarkDotNet `-report-full.json` against a committed baseline JSON and exits non-zero on any >20% mean regression, plus a `CompareBaseline.Tests` xUnit project that PROVES the gate fires correctly. Wire a `benchmarks` CI job (push-to-main only) that runs the benchmarks and the gate.

Purpose: PERF-06 is the hard requirement — BenchmarkDotNet has no built-in regression gate. This plan supplies the missing mechanism and, critically, proves it works (exit 1 on a >20% injected regression, exit 0 within threshold) so the gate is trustworthy, not decorative.

Output: The comparison tool, its proving self-test, and the CI job.
</objective>

| committed baseline JSON → gate | the gate trusts the committed baseline as the regression reference |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |

| T-19-03-01 | Tampering | Gate silently skips renamed/removed benchmark | mitigate | Tool WARNS on baseline-method-missing and new-method-added (RESEARCH Pitfall §6); never silently passes a dropped benchmark |
