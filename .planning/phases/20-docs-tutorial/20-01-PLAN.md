<objective>
Make the TicTacToeDuel sample a correct, bootable tutorial target and integration harness (DOCS-06). Two concrete, verified bugs/gaps block the rest of the phase:

1. `matchmaking.html` enqueues with `poolName: "tictactoe"`, but the `tictactoe` ladder only pairs tickets in the `default` pool (a null PoolName routes there). The UI "Find Match" path silently never forms a match. Fix: send `poolName: null`.
2. The sample's `Program` is top-level-only with no public accessor type, so a test project cannot reference it. The DOCS-02 smoke test (Plan 04) needs a referenceable `Program` type. Add `public partial class Program { }` at the end of the file.

Purpose: Both are Wave-1 prerequisites — the tutorial prose (Plan 04) tells readers to open `matchmaking.html` and click Find Match, and the CI smoke test references the sample. Neither can be honest until these are fixed.
Output: Corrected `matchmaking.html`; `Program.cs` with a public `Program` partial.
</objective>
