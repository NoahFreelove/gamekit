<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| browser → app (static assets) | the client is fully untrusted; assets must be local (no CDN supply-chain or egress) |
| browser → /auth/login/guest | unauthenticated onramp; must not collect PII; issues a player-scoped JWT only |
| browser → /ws/game (run-summary) | the client self-reports timing; treated as untrusted and re-validated server-side in 21-04 (the client cannot write results directly) |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-21-07 | Information Disclosure | CDN/cloud egress from wwwroot | mitigate | All JS/assets vendored locally; CI grep gate asserts no CDN/analytics URLs in wwwroot (must-NOT) |
| T-21-08 | Information Disclosure / Privacy | guest onboarding PII | mitigate | Guest flow collects no PII fields; no analytics script; grep + judgment gate |
| T-21-09 | Tampering | browser self-reports match result | transfer | The client only SENDS a run-summary; authoritative completion is posted by the service-token GameServer (21-04). Client JWT cannot reach session-complete (R7, enforced in 21-04/21-06) |
| T-21-10 | Tampering | vendored engine supply chain | mitigate | three.js pinned to a verified official release tag; MIT license recorded in REUSE.toml + THIRD-PARTY-NOTICES.md; reuse lint gate (R11) |
</threat_model>
