## A3 — STRATEGY RESOLUTION (LOCKED — READ BEFORE WIRING)

`src/GameKit.Matchmaking/Services/MatchmakerTickerService.cs` takes a SINGLE constructor parameter `IMatchmakingStrategy strategy` (ctor line ~103; field assigned line ~127; used `_strategy.Match(candidate, poolScratch, now)` line ~477) — NOT keyed, NOT by-Name, NOT `IEnumerable`. That one resolved strategy self-filters per ladder via its `FindLadderConfig`. `AddMatchmaking()` calls `AddStrategyServices()` (`src/GameKit.Matchmaking/Builder/MatchmakingBuilderExtensions.Strategy.cs` lines 67–71, invoked from `MatchmakingBuilderExtensions.cs:124`), which Scrutor-scans `FromAssemblyOf<EloRangeMatchmakingStrategy>()` and registers `EloRangeMatchmakingStrategy` as an `IMatchmakingStrategy` singleton. MS.DI returns the **LAST-registered** descriptor for a service type, so a custom `AddSingleton<IMatchmakingStrategy, BestTimeMatchmakingStrategy>()` placed BEFORE `AddMatchmaking()` is **SHADOWED** by EloRange (the Strategy.cs XML doc lines 50–56 advising "register BEFORE" is wrong for a *different* impl — its "dedups by service+impl pair" only blocks double-registering the *same* impl).

**LOCKED registration (no ambiguity, no empirical step):** call

```
services.Replace(ServiceDescriptor.Singleton<IMatchmakingStrategy, BestTimeMatchmakingStrategy>())
```

**AFTER** `AddMatchmaking()` — this removes the scanned EloRange descriptor and registers exactly one strategy. `Replace` lives in `Microsoft.Extensions.DependencyInjection.Extensions` (already used at `MatchmakingBuilderExtensions.Ticker.cs:61`). The R5 resolution test in 21-06 (`GetRequiredService<IMatchmakingStrategy>()` is `BestTimeMatchmakingStrategy`) is the gate that proves it. Note: `IRankingAlgorithm` selection is different — Rankings selects by the ladder's `Algorithm` string field matched against `IRankingAlgorithm.Name`, so the custom algorithm only needs `ladder.Algorithm = "time-margin"` + its singleton registered (the EloRange-style shadowing concern does not apply to rankings since selection is by Name).
