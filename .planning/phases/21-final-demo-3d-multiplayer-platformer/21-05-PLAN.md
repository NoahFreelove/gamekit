Package the entire demo as a single loadable artifact: a multi-stage Dockerfile builds the Platformer3D app image, one `docker compose up` brings up app + Postgres + Redis (only the app port published), and a documented `docker save` tarball makes it transferable for fully-offline `docker load`. This delivers ROADMAP success criteria 1 (single loadable image) and 6 (one-command offline) and requirement R3, while keeping the R11 license gate green.

Purpose: This is the "load and go" capstone artifact. It must come up reproducibly offline with zero cloud credentials and make no outbound cloud/SaaS/CDN call (must-NOTs), with Postgres/Redis reachable only on the internal Docker network (never published to the host).

Output: Dockerfile, compose file, .dockerignore, Postgres init SQL, and a README with the run + offline-tarball commands.
</objective>
