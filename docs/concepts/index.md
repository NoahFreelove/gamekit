# GameKit Concepts

> Every algorithm and strategy in GameKit is an interface the developer can replace — install
> only what you need, own the rest, depend on no cloud service.
>
> — GameKit design principle (CLAUDE.md)

This section contains per-package conceptual documentation: what each package does, the
**public interfaces it exposes** (the "replaceable seam" story), and the line between what
GameKit owns and what the game developer must implement or configure.

For full member-level API docs (method signatures, parameters, XML doc comments), see the
[API reference](../../api/index.md) generated by DocFX from the source XML comments.

## Packages

### Foundation

| Package | What it does |
|---------|-------------|
| [GameKit.Core](core.md) | Player schema, session lifecycle, GDPR pipeline, rate-limiting, fluent builder. Observability (`AddGameKitObservability`) and health checks (`AddGameKitHealthChecks`) ship here as opt-in extension methods — not separate packages. |

### Authentication

| Package | What it does |
|---------|-------------|
| [GameKit.Auth](auth.md) | Guest accounts, password auth, OAuth providers, JWT issuance, refresh-token rotation, identity linking, account merge, audit trail. BCrypt default; Argon2id opt-in. |
| [GameKit.Auth.Argon2](auth-argon2.md) | Opt-in `IPasswordHasher` backed by Argon2id (Isopoh). Transparent BCrypt → Argon2id migration window via `.UseArgon2()`. |
| [GameKit.Auth.Apple / .Epic / .Google](auth-providers.md) | Plug-in `IOAuthProvider` implementations for Apple, Epic, and Google. Each must be registered explicitly — Scrutor scans only the `GameKit.Auth` assembly by default. |

### Game Services

| Package | What it does |
|---------|-------------|
| [GameKit.Rankings](rankings.md) | Skill ratings (Glicko-2 default, replaceable via `IRankingAlgorithm`), leaderboards, season archiving, GDPR export, service-account tokens. |
| [GameKit.Matchmaking](matchmaking.md) | Redis-backed queue + ticker, party support, proposal accept/decline, backfill, admin controls. Matching strategy replaceable via `IMatchmakingStrategy` (EloRange default). |
| [GameKit.Presence](presence.md) | Player online/in-match/offline tracking in Redis. Write-side seam via `IPresenceWriter`; read-side via `IPresenceProvider` (Core). |
| [GameKit.Lobby](lobby.md) | Pre-game lobby rooms with REST API + SignalR real-time hub + ready-check state machine. Chat gate via `ILobbyMessageHandler`; typed hub client via `ILobbyClient`. |

### Operations

| Package | What it does |
|---------|-------------|
| [GameKit.Admin.UI](admin-ui.md) | Blazor Server admin console + admin HTTP API. Player ban/unban, search, rank-adjust, matchmaking controls, health panel, admin-user CRUD. Requires `GameKit.Auth`. |
| [GameKit.OpenApi](openapi.md) | Configuration-only: exposes `/openapi/v1.json` with admin paths excluded. No public interfaces — extension point is the `ShouldInclude` endpoint predicate. |
| [GameKit.Cli](cli.md) | `gamekit` CLI tool: migration orchestration, admin bootstrap, service-token management, `pg_dump`/`pg_restore` wrappers. Spectre.Console.Cli command surface. |

## The Replaceable-Interface Story

GameKit's architecture is built around the principle that every algorithm and strategy is
an interface:

| Interface | Package | Default | Replace When |
|-----------|---------|---------|--------------|
| `IMatchmakingStrategy` | `GameKit.Matchmaking` | `EloRangeMatchmakingStrategy` | You need custom bracket logic |
| `IRankingAlgorithm` | `GameKit.Rankings` | `Glicko2Algorithm` | You want Elo, TrueSkill, or a custom model |
| `IPasswordHasher` | `GameKit.Auth` | BCrypt (`BCrypt.Net-Next`) | You want Argon2id (`GameKit.Auth.Argon2`) |
| `IOAuthProvider` | `GameKit.Auth` | Steam + Discord built-in | You add Apple/Epic/Google or a custom provider |
| `ILobbyMessageHandler` | `GameKit.Lobby` | `NullLobbyMessageHandler` (always relay) | You add rate-limiting or content moderation |
| `IPresenceWriter` | `GameKit.Presence` | `RedisPresenceProvider` | You use a custom presence backing store |
| `IPlayerSearchService` | `GameKit.Admin.UI` | Display-name prefix + UUID lookup | You add Elasticsearch or a custom index |
| `IAdminAuditWriter` | `GameKit.Admin.UI` | No-op (null) | You write audit records to a custom store |
| `IPlayerDisplayNameResolver` | `GameKit.Core` | Player `username` column | You resolve display names from a social graph |
| `IGameKitRateLimitPolicies` | `GameKit.Core` | Fixed-window per-player | You apply custom rate-limit policies |
| `IGdprDeleteExtension` | `GameKit.Core` | — (port only; each package registers its own) | You have custom PII tables to clean up |
| `IPartyCodeGenerator` | `GameKit.Matchmaking` | Crypto-random alphanumeric | You want shorter or structured invite codes |

All registrations use `TryAdd*` semantics — register your implementation before the
corresponding `Add*` builder call and GameKit will use yours.
